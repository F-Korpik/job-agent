# Privacy

job-agent is a personal tool used only by its author.

- It reads e-mails with the label `oferty` from the author's own Gmail account, using the read-only scope `gmail.readonly`. It cannot send, modify or delete e-mails.
- Job offers extracted from those e-mails are stored only in the author's own Google Sheet.
- E-mail content is sent to the Groq API for offer extraction. No data is shared with anyone else.
- No data from other users is collected.
